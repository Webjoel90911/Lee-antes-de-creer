1. Conexión con GitHub

Crea un token en GitHub → Settings → Developer settings → Fine-grained tokens, con permiso Contents: Read and write solo para este repositorio. Se guarda únicamente en este navegador.

Apariencia

Las imágenes se suben a la carpeta images/ de tu repositorio. Al pulsar «Guardar en GitHub», el título, la descripción, el logo y los colores también se actualizan en las etiquetas que leen Google y las redes sociales.
